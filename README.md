# Leaf & Brew Box

A responsive tea subscription preferences form built with HTML and Tailwind CSS.

The project focuses on creating a clean, structured interface for managing subscription preferences, customer details, delivery information, and payment methods.

## Features

* Responsive layout using Tailwind CSS
* Subscription tier selection
* Multiple taste preferences
* Loose leaf or bagged tea selection
* Dietary restriction input
* Customer information fields
* Saved delivery address display
* Saved payment method display
* Responsive form layout for different screen sizes
* Inline SVG icons
* Custom visual styling using Tailwind utility classes

## Tech Stack

* HTML5
* Tailwind CSS
* SVG
